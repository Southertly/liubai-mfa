# Windows MFA 二级页面分组列表视觉设计说明

## 目标

将添加账户、设置、锁定三个二级页面从“多个独立卡片”重排为参考图所示的紧凑分组列表：分组标题、统一浅色圆角面板、行内图标、主标题、辅助说明、右侧状态或箭头。页面仍遵循 WinUI 3/Fluent 的主题资源、键盘焦点和桌面窗口适配，不移植参考图顶部的手机统计区。

## 范围与不变项

- 修改范围仅限 Windows WinUI 页面和共享视觉资源，不修改 Android/HarmonyOS。
- 保留现有导航、扫码、图片导入、手动输入、锁定、Windows Hello、电脑密码、备份导入/导出和启动保护事件。
- 不改变密钥存储、备份加密、锁定策略或错误处理逻辑。
- 不新增云同步、账号系统或新的设置功能。

## 共享视觉规则

### 页面宽度与间距

- 页面内容在窗口内居中，水平可用空间不足时随窗口收缩。
- 内容最大宽度约为 `680 DIP`，避免固定窄栏造成大面积空白。
- 页面左右内边距沿用现有页面资源；分组标题与面板左边缘对齐。
- 分组标题与面板之间使用紧凑间距；分组之间使用明显但不过大的垂直间距。

### 分组面板

- 每个逻辑分组只使用一个圆角面板，避免“一行一张卡片”。
- 面板使用 `CardBackgroundFillColorDefaultBrush` 和主题描边资源，圆角沿用 WinUI 主题尺寸。
- 行高统一：单行操作约 `56 DIP`，带辅助说明的行约 `68 DIP`。
- 同组行之间使用内缩分隔线，分隔线不延伸到圆角边缘。
- 面板不额外叠加阴影，保持 Fluent 的轻量层级。

### 图标、文字与状态

- 每行左侧使用 `FontIcon`/`SymbolIcon`，图标槽宽固定，主色使用主题强调色。
- 主标题使用 `Microsoft YaHei UI`，约 `16 DIP`、常规或半粗；辅助说明约 `12–13 DIP`、次要文字色。
- 分组标题约 `13–14 DIP`，使用次要文字色。
- 右侧状态、开关或箭头固定在右侧；状态文字不依赖颜色单独表达含义。
- 页面标题约 `28 DIP`，不再使用过大的标题占据内容区。
- 所有可点击行保持明确的键盘焦点视觉和可访问名称。

## 页面结构

### 设置页

保留返回按钮、标题和“仅保存在本机”状态。内容分为两组：

1. **安全**
   - 立即锁定：右侧显示“锁定”，点击行为不变。
   - 启动保护：右侧显示“未开启/已开启”，点击行为不变。
2. **数据**
   - 导入加密备份：右侧显示“选择文件”。
   - 导出加密备份：右侧显示“导出”。

底部保留本地存储和恢复密码提示，但使用普通说明文字，不再作为独立卡片。

### 添加账户页

保留返回按钮、标题和状态提示。移除当前大面积蓝色英雄按钮，改为两组列表：

1. **推荐方式**
   - 截图并扫描二维码：整行可点击，右侧显示箭头。
2. **其他方式**
   - 从图片导入：整行可点击，右侧显示箭头。
   - 手动输入：整行可点击，右侧显示箭头。

原有帮助说明可以作为行内辅助文字，不能撑高整组面板。

### 锁定页

锁定页不提供返回按钮。页面中心保留锁定图标、标题和安全说明，下面使用一个分组面板承载解锁操作：

- 使用 Windows Hello 解锁：主操作行。
- 使用电脑密码解锁：备用操作行；当不可用时沿用现有折叠逻辑。

自动重新锁定和“本地优先”保留为面板下方的说明文字。

## 响应式与主题

- 宽窗口：内容居中并使用最大宽度，左右留白平衡。
- 窄窗口：内容宽度收缩，长文本换行，行内右侧操作保持可见。
- 使用主题资源，不硬编码浅色背景或深色文字；浅色和深色模式均可读。
- 分组面板、行和按钮不重复嵌套边框，避免出现双重卡片。

## 验收标准

- 三个二级页面均呈现“分组标题 + 统一圆角面板 + 行分隔线”的结构。
- 同一页面内的列表行宽度、图标槽、左右内边距和行高一致。
- 设置页不再出现四张宽度不同的独立卡片；添加账户页不再出现突兀的大蓝色块。
- 所有原有事件处理和安全相关状态保持不变。
- XAML 可解析，Release 构建和测试通过，MSIX 能安装并启动。
- 启动后的窗口标题为“留白 MFA”，主窗口响应正常。
