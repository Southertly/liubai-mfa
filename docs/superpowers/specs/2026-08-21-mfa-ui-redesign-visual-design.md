# 留白 MFA Windows 1.0.0.7 视觉重设计方案

## 目标

在不改变 MFA 本地优先、安全边界和既有交互约定的前提下，重做 Windows 主界面的视觉层：让账户、验证码、复制反馈、空状态、设置和锁定入口形成统一的 Fluent 视觉系统。

## 视觉方向

- 风格：Fluent 2 + Minimalism / Swiss，强调网格、留白和清晰层级。
- 背景：浅蓝白 `#F0F9FF`，使用 WinUI Mica/ThemeResource 适配主题。
- 主色：安全蓝 `#0369A1`；辅助高亮 `#0EA5E9`。
- 安全状态：保护绿 `#16A34A`；错误/危险使用系统 Critical brush。
- 卡片：白色表面、细边界、轻微层次，不使用大面积玻璃模糊或装饰性渐变。
- 字体：沿用系统 Segoe UI；验证码使用等宽字体，保证数字对齐和快速扫描。
- 动效：150–250ms 的轻量状态反馈；复制反馈不推动布局，支持键盘焦点。

## 主界面结构

1. 标题区：左侧“验证码”和本机保护状态，右侧只有设置与添加两个 44px 操作按钮。
2. 搜索区：圆角搜索框，保留服务、账户、分组搜索语义。
3. 分组区：轻量胶囊筛选，选中状态使用安全蓝填充并保持高对比度。
4. 账户区：账户安全卡片；服务图标、账户信息、验证码和倒计时分层排列；底部进度条表达更新时间。
5. 空状态：安全盾牌/锁定视觉、明确主行动和简短本地加密说明。
6. 底部状态：仅保留验证码自动更新和本机保护状态，不放备份按钮。

## 交互表现

- 点击账户卡片复制验证码；成功后验证码区域显示“已复制”约 1 秒，再恢复数字。
- 账户卡片向左拖动揭示“编辑 / 查看密钥 / 删除”；保留键盘和辅助技术可达路径。
- 设置菜单按“安全”和“数据”组织，备份与恢复只出现在设置入口。
- 添加入口承接扫码、图片导入、手动输入等已有流程。
- 锁定页优先 Windows Hello，并提供电脑密码解锁回退。

## 验收标准

- 浅色和深色主题下正文、验证码、边界和焦点均可读。
- 所有顶部图标按钮有可访问名称，点击区域不小于 44px。
- 账户卡片在空状态、已复制、即将刷新和左滑动作状态下不发生布局跳动。
- 不引入独立复制按钮、右键菜单或底部备份入口。
- UI 构建、核心回归和 CodeBehindCheck 通过后才标记完成。
