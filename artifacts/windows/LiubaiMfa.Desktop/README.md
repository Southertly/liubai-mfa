# 留白 MFA · Windows

支持手动添加真实 TOTP 密钥、加密保存、账户编辑删除、搜索和分组、验证码倒计时，以及 Windows 身份验证和锁定。

设置、添加和编辑采用独立页面，支持返回及 Escape 取消。主题位于设置中。账户列表、设置和表单各自滚动，备份及删除使用确认弹窗。

首页顶部背景铺满窗口，搜索与账户列表使用同一层左右边距：普通窗口 24 像素，窄窗口 16 像素，避免居中容器叠加造成左侧空带。此调整从安装预览版 `0.1.9.0` 提供。

`0.1.10.0` 将相同边距应用于设置、添加／编辑及二维码核对页，并统一底部状态栏。二级页在超宽窗口限制为 1120 像素并居中，页头和内容同步对齐；弹窗中的长文件名、分组名等文字可自动换行。

普通开发启动使用 `%LOCALAPPDATA%\Liubai MFA Electron`，不会扫描旧版或读取阶段 1B 的 `Liubai MFA Electron Dev`。新库初始为空，首次保存账户才生成设备密钥和账户密文。安装预览版使用下文的独立包目录。

## 检查更新

在「设置 → 关于」可以查看当前版本并手动检查更新。发现新版时点「查看新版」，到项目的 GitHub 发布页下载对应渠道的 Windows x64 安装包。

从 1.0.2 起，正式版在新版 MSI 提供 SHA-256 摘要时会显示「下载更新」。下载期间可以取消。校验通过后点击「安装更新」并确认，应用会退出并打开 Windows 安装程序，沿用原目录和安装范围。遇到下载或校验失败时，可以重试或打开 GitHub 发布页。

发布 Windows 预览版时，在 [项目发布页](https://github.com/Southertly/liubai-mfa/releases) 使用 `windows-preview-v<四段版本>` 标签，并上传同版本的 `LiubaiMfa-Preview-<四段版本>-x64.msix`。例如发布 `0.1.13.0` 时，标签是 `windows-preview-v0.1.13.0`，附件是 `LiubaiMfa-Preview-0.1.13.0-x64.msix`。发布后才会被检查到。升级包沿用同一 MSIX 包标识及受信任的签名。

Windows 正式发布使用 `windows-v<三段版本>` 标签和同版本的 `LiubaiMfa-<三段版本>-x64.msi` 或 `LiubaiMfa-<三段版本>-x64-unsigned.msi` 附件。正式版只检查正式发布，预览版只检查预览发布。

## 正式版 MSI

Windows 11 x64 的 1.0.3 安装包及 SHA-256 校验文件可在 GitHub 下载。该版本 MSI 未签名。[Windows 1.0.3 发布页](https://github.com/Southertly/liubai-mfa/releases/tag/windows-v1.0.3)

MSI 可以选择程序安装目录，并在桌面和开始菜单创建快捷方式。自定义目录应只允许当前用户、系统和管理员修改程序文件。账户库位于当前 Windows 用户的 `%APPDATA%\LiubaiMfa\accounts`，应用程序的安装和卸载不会操作该目录。升级时选择原来的程序安装目录。

预览版和正式版使用独立账户库。转入时先在预览版导出加密备份并单独保存恢复密钥，再在正式版「设置 → 从备份恢复」导入。确认正式版的账户和验证码可用后再卸载预览版。

在 Windows 11 x64 上安装 Node.js 22、.NET 8 SDK 和 Windows SDK 后，在当前目录运行：

```powershell
npm ci
.\packaging\build-msi.ps1 -Version 1.0.3
```

WiX SDK 和扩展按项目固定版本获取。生成 MSI 位于 `../AppPackages/Desktop/`。未签名安装包以 `-unsigned` 标记，发布页注明签名状态并提供 SHA-256 校验值。使用可信证书时可以传入 `-CertificateThumbprint` 签名并验证时间戳。导入账户可使用现有的加密备份恢复入口。

## 安全设置

- 新空库默认关闭启动保护。设置中的开关每次改变都先通过系统验证；失败保持原值。
- 优先 Windows Hello；不可用时使用系统电脑密码窗口，并核对身份属于当前 Windows 用户。密码不进入网页、日志或设置。
- 启用保护后，应用失焦按设置的时间自动锁定，默认 60 秒；系统锁屏或睡眠立即锁定。手动锁定后必须验证才能恢复；本地核心异常退出或重新连接也保持锁定。
- 系统验证最多等待 120 秒；超时、锁定和退出使迟到结果失效。系统凭据窗口可能仍需用户手动取消，但其迟到结果不会解锁。
- 锁定由 C# 核心执行，锁定时拒绝所有账户操作；网页同步清空账户和密钥表单。窗口句柄只能由 Electron 主进程传入，并验证属于宿主的父进程。

## 账户和存储

- 手动输入只接收 Base32，支持现有 TOTP：SHA-1、6 位、30 秒。手动输入不接受 URI；二维码使用专用入口；重复密钥拒绝添加。编辑名称、分组或颜色不会替换密钥。
- 密钥输入默认掩码；提交、关闭、锁定和断连清空输入。常规 DTO 只有 `id/issuer/account/group/color/code/expiresAt`。
- DPAPI CurrentUser 保护设备密钥；账户使用既有 BackupCrypto 加密信封。文件为 `device-key.v1.bin`、`accounts.v2.json`，初始化标记为 `initialized.v1`，目录锁为 `electron.lock`。
- 独立保护设置为 `protection.v1.json` 和初始化标记。已有库的必要文件缺失、解密失败或损坏均拒绝访问与覆盖；原子替换失败保留旧密文。
- 首次初始化涉及多个文件，不保证跨文件原子性；中断残留时拒绝重新初始化，不自动删除文件。
- 验证码复制由原生层生成并写入，30 秒后尝试清理本应用仍拥有的内容；强制终止或系统剪贴板占用时不能保证清理。
- 页面禁止外部网络请求和任意导航。手动检查更新由主进程从项目的公开发布渠道读取版本。

## 加密备份与恢复

在设置中使用“导出加密备份”和“从备份恢复”。导出会重新验证 Windows 身份，生成 v2 加密备份与独立恢复密钥；恢复密钥显示 30 秒，离开窗口即清空。确认已单独保存密钥后选择新文件名，只有核心成功落盘才显示完成；已有文件不会被覆盖。

恢复先选择文件、输入恢复密钥、预览新增/重复数量，再确认追加。相同密钥跳过，ID 冲突生成新 ID，原账户保持原样。预览后账户库发生变化时必须重新预览。兼容 v2 中未指定颜色的账户，默认使用蓝色。

单文件最多 5 MiB，输入及合并后最多 1000 个账户；只接受本地核心支持的合法 TOTP 字段。待确认备份与导入数据保留最多 120 秒，锁定、取消、断连和重启使旧操作失效。网页不能提供文件路径；系统选择窗口由主进程打开，密文读写由核心执行。恢复密钥不会写入日志、URL、设置或账户列表。

## 二维码导入

点击“添加账户”，选择“扫描当前屏幕”或“从二维码图片导入”。屏幕扫描会临时隐藏窗口，扫描窗口所在的显示器，随后恢复窗口。识别后可以核对并修改服务名称、账户、分组和颜色，确认后才保存；原始密钥及 URI 只留在 C# 核心，不填入网页密钥字段。

支持 PNG、JPEG、BMP，单文件最多 25 MiB、1600 万像素、边长不超过 10000。只支持标准 TOTP、SHA-1、6 位、30 秒；HOTP、其他参数、未知参数和无效编码明确拒绝。发现多个不同二维码时要求使用仅含一个二维码的图片；重复密钥不会再次写入。

草稿有效期 120 秒，关闭、取消、锁定、断连或重启即失效。系统图片窗口和屏幕截图路径由主进程提供，网页没有任意文件读取入口。正常扫描结束删除临时截图；异常崩溃或系统故障不能保证清理。二维码图片和屏幕都在本机处理，不联网识别。

## 账户转入

转入账户时使用二维码导入或 v2 加密备份恢复。此前迁移生成的账户库也可以继续读取。

## Windows 11 x64 MSIX 预览包

在已安装 .NET 8 SDK、Windows SDK 10.0.26100.0 和 Electron 开发依赖的机器上，从此目录运行以下命令。签名使用现有留白 MFA 开发证书的指纹。若需要新建开发证书，可运行 `.\packaging\new-development-certificate.ps1`。

```powershell
.\packaging\build-preview.ps1 -CertificateThumbprint <开发证书指纹>
```

生成并校验签名后的安装包位于 `../AppPackages/DesktopPreview/`，文件名包含版本号。可在信任该开发证书的 Windows 11 x64 电脑上安装，从开始菜单打开“留白 MFA 预览版”。安装包内含 Electron 和自包含 .NET 8 核心。

预览版使用独立包身份 `com.mfaverifier.app.windows.electronpreview`，其配置目录为 `LiubaiMfaDesktopPreview`。账户库位于该目录的 `accounts`。

## 自动锁定时间

在“设置 → 安全 → 离开应用后锁定”选择 30 秒、1 分钟、2 分钟、5 分钟、10 分钟或不自动锁定，选择后立即保存，重启继续使用。默认一分钟，只有开启“打开应用时验证身份”后才启用离开窗口计时；切换到其他窗口或最小化开始计时，回到应用取消计时，下次离开重新开始。系统身份验证和系统文件选择期间暂停，结束后重新判断。

“不自动锁定”仅关闭离开应用后的计时。Windows 锁屏、休眠及手动锁定仍独立生效。设置保存失败时显示错误并回到原选项，锁定状态拒绝修改。

此偏好保存在浏览器配置目录下的 `auto-lock.v1.json`，不修改账户密文、设备密钥或启动保护配置。缺失或损坏设置回退为一分钟。自动回归和 Electron 界面验证使用独立临时库，不读取真实账户，不触碰系统剪贴板。

## 自定义分组与标签颜色

在添加、编辑或二维码核对页，选择已有分组，或选择“新建分组…”后输入自定义名称。名称最多 40 字符；空名称不能保存，大小写同名复用已有分组。编辑页的新名称在保存账户时创建，取消编辑不会创建分组；也可通过主页单独新建。

标签颜色改为九色圆点，与 Android、HarmonyOS 的共同配色一致；点击选择，勾选和外圈表示当前颜色，也可使用键盘方向键。新颜色同时支持账户保存、编辑回显和加密备份恢复。升级不会自动修改已有账户的分组或颜色。

账户主页的组名右侧可点击“重命名”。弹窗提示该组全部账户数量，保存后一次更新整组，即使搜索仅显示部分账户也不会遗漏。新名称与其他组重名时拒绝保存，不会自动合并；未分组不提供整组改名。取消、原名保存或错误均不改写账户，锁定时关闭弹窗并清空名称。

分组标题使用浅绿、浅橙圆角文件夹样式，显示整组账户数量，点击展开或收起。从账户卡片的非按钮区域拖到目标文件夹即可移动；收起的分组也可投放，接近列表上下边缘时自动滚动。拖动期间临时补充搜索隐藏的目标组和“未分组”，松开后以核心成功保存的结果刷新列表。取消、同组或外部拖入不会保存；失败显示提示并保留原分组。也可继续通过编辑账户页的分组选择操作。

移动只更改当前账户的分组，保留名称、密钥、标签颜色、ID 和创建时间。拖动标记及拖图不包含账户信息或验证码，锁定及断连清理拖动状态。

主页点击“新建分组”即可单独创建，不需要先添加账户。空组显示 0，可直接接收拖动、重命名，最后一个账户移出后仍保留；重启继续显示。命名分组固定在“未分组”之前。窄窗口的文件夹按钮也可新建分组。

空分组右侧提供“删除”，确认后只删除分组名单。核心会重新检查，有账户的分组不能删除；未分组也不提供删除入口。删除空组不改账户密文、设备密钥或备份。分组背景按组名稳定分配绿、橙、蓝、紫、粉、青六种柔色，刷新和重启保持一致，不增加账户字段或配置文件；未分组使用中性色。

分组名单采用当前 Windows 用户加密保护，独立保存到 `groups.v1.bin`，初始化标记为 `groups.initialized.v1`，中断时的加密提交记录为 `groups.pending.v1.bin`。首次读取旧库只归纳原分组，不自动写文件；单独创建或重命名空组不改账户密文、设备密钥及保护设置。已存储的分组记录损坏或缺失时拒绝访问，避免误当空组覆盖。

新版 v2 加密备份追加单独加密的分组名单，恢复可保留空组；账户载荷保持兼容旧版。旧备份仍可恢复，预览会说明新增分组数；预览后账户或分组变化时须重新预览。最多 1000 个命名分组。
