# 服务图标来源

图标随 Windows 安装包分发，在账户列表中用于识别对应服务。

- Google 彩色图标取自 [Devicon v2.16.0](https://github.com/devicons/devicon/blob/v2.16.0/icons/google/google-original.svg)。附同目录 MIT 许可证。
- Microsoft 四色标志取自 [Microsoft Entra 品牌文档的素材](https://learn.microsoft.com/en-us/entra/identity-platform/media/howto-add-branding-in-apps/ms-symbollockup_mssymbol_19.svg)。
- OpenAI、Meta、X、GitHub、Alibaba Cloud、Bitwarden 取自 [Simple Icons 13.21.0](https://github.com/simple-icons/simple-icons/tree/13.21.0/icons)，Meta、Alibaba Cloud 和 Bitwarden 使用对应品牌色。
- 腾讯云图标取自 [腾讯云官网图标](https://www.tencentcloud.com/favicon.ico)，保留其中原始 PNG。
- 欧易、PayPal、Wise、火山引擎使用各自的官网图标。[欧易](https://www.okx.com/cdn/assets/imgs/253/59830BB78B18A776.png) · [PayPal](https://www.paypalobjects.com/webstatic/icon/pp258.png) · [Wise](https://wise.com/public-resources/assets/icons/wise-personal/favicon_32x32.png) · [火山引擎](https://portal.volccdn.com/obj/volcfe/misc/favicon.png)
- 华为云与 JumpServer 使用官网图标并以 PNG 分发。[华为云](https://www.huaweicloud.com/favicon.ico) · [JumpServer](https://jumpserver.org/images/logo/favicon.ico)

各品牌标志归各自权利人所有。Vaultwarden 使用应用内置钥匙图标。
